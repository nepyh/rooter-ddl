# 🗄️ [rooter] DB DDL & Migration Repository

우리 AI 서비스의 데이터베이스(DB) 구조 설계도와 버전 관리를 위한 저장소입니다.  
**Flyway**를 사용하여 DB 마이그레이션을 관리합니다.

---

## 🛠️ 기술 스택 (Tech Stack)

- **Database:** PostgreSQL, Redis
- **Migration Tool:** Flyway

---

## 📂 폴더 구조 및 파일 명명 규칙

### 1. 폴더 구조

모든 마이그레이션 SQL 파일은 아래 경로에 위치해야 합니다.
`db/migration/`

### 2. 파일 이름 규칙 (Naming Convention)

Flyway 버전 관리를 위해 아래 규칙을 엄격히 준수합니다.

- 형식: `V<버전번호>__<설명>.sql` (※ 언더바 2개 필수)
- 예시: `V1__init_user_table.sql`, `V2__add_google_id.sql`

---

## 📝 데이터베이스 테이블 정보 (현재 V1 기준)

### 1. `users` (회원 메인 테이블)

- 일반 가입 유저(아이디/비번) 및 구글 소셜 로그인 유저 통합 관리
- 학업 정보(학교, 학년, 반, 시험과목/범위) 및 마이페이지 프로필 정보 포함

### 2. `user_unavailable_times` (공부 불가능 시간 테이블)

- 유저별 월~일요일 사이의 공부 불가능 스케줄 관리 (1:N 관계)

---

## ⚠️ 주의 사항 (Rule)

1. **과거 파일 수정 금지:** 이미 메인 DB에 반영된 이전 버전의 SQL 파일(예: `V1`)은 절대로 내용을 수정하면 안 됩니다.
2. **변경 사항은 새 파일로:** 테이블 구조를 변경하거나 추가할 때는 무조건 다음 버전 파일(예: `V2`)을 새로 생성하여 작성해야 합니다.
